Política de Privacidad

2. Datos que podemos recoger

El formulario de contacto solicita nombre, correo electrónico y localidad de la vivienda; también permite facilitar teléfono, tipo de servicio y un mensaje. Se recomienda no incluir datos personales innecesarios ni información sensible en el mensaje.

Formspree procesa los envíos para prestar el servicio del formulario. También pueden tratarse datos técnicos asociados al envío conforme a la información de privacidad aplicable de Formspree.

3. Finalidades y base jurídica

Los datos se tratan para responder a consultas, valorar necesidades relacionadas con una vivienda y, si procede, preparar una propuesta solicitada por la persona interesada. La base jurídica es la aplicación de medidas precontractuales a petición de la persona interesada cuando corresponda.

Los datos no deben utilizarse para enviar publicidad no solicitada. Cualquier uso adicional requerirá una base jurídica adecuada y, cuando corresponda, consentimiento separado.

4. Proveedor y destinatarios

Los envíos del formulario se realizan mediante Formspree, que trata los datos para prestar el servicio del formulario. Los datos pueden comunicarse a proveedores de servicios cuando sea necesario para gestionar la web y responder a las consultas. No se venden datos personales.

5. Conservación

Los datos se conservarán durante el tiempo necesario para responder y gestionar la consulta y, cuando corresponda, durante los plazos legalmente exigibles. Se eliminarán o bloquearán cuando dejen de ser necesarios para la finalidad para la que fueron recogidos, salvo obligación legal de conservación.

6. Analítica web y cookies

La web puede utilizar Google Analytics 4 para elaborar estadísticas de uso únicamente si la persona visitante acepta expresamente las cookies de analítica. Si las rechaza, la analítica permanecerá desactivada. La elección puede modificarse posteriormente mediante la opción de configuración de cookies.

Google Analytics es un servicio de Google. La analítica se activa solo tras el consentimiento correspondiente y se aplican los ajustes disponibles en la configuración del servicio.

7. Derechos

La persona interesada puede solicitar, cuando proceda, el acceso, rectificación, supresión, oposición, limitación del tratamiento y portabilidad, así como retirar un consentimiento sin que ello afecte a la licitud del tratamiento previo. Puede escribir a info@habitaratlantico.es. También puede presentar una reclamación ante la Agencia Española de Protección de Datos (AEPD).

8. Seguridad

Se aplican medidas técnicas y organizativas adecuadas para proteger los datos personales y limitar el acceso a quienes los necesiten para gestionar la consulta.

9. Cambios

Esta política se actualizará cuando cambien los tratamientos, los proveedores o las obligaciones legales. La versión publicada deberá indicar la fecha de su última actualización real.
